# Motivation

## Aims
- critical: cite article when taking notes / writing a ms
- critical: keep track of articles of interest, including a local copy of the pdf
- critical: take notes on articles
- normal: organize articles per topic
- normal: organize articles per projects
- optional: synchronize the library on several devices
- optional: share articles / collections with colleagues (for collaborative writing / journal clubs)

## Why zotero?
free software
unix supported
not so bad in the end

# Workflow

Start with [Mastering Zotero](http://zotero-manual.github.io/).
also the official https://www.zotero.org/support/

Import from a source with high quality metadata (pubmed is my default).
now attach pdf if open access

otherwise use "add attachment from source folder" (attach, renam, delete source file)

Use plugins:
- zotfile for attachments
- quicklook for fast pdf preview
- betterbibtex for formatting (see below)

Tags vs collections

"Smart collections" are created from the search window.
useful ones:
- created since one day / week / month
- modified from one day /
